# Ucentral_Sistema_evaluaci-n_creacion_cupos_para_clientes_Vargas_Barrera
## Sistema de evaluación para la creación y asignación de cupo para clientes de una compañía  de consumo masivo
En las empresas de consumo masivo, el proceso de vinculación de clientes requiere evaluar los riesgos de prevención de lavado de
activos (SARLAFT/LAFT) y la capacidad crediticia antes de autorizar ventas a crédito. Actualmente, los análisis se realizan mediante
consultas manuales y cruces entre bases de datos externas (listas restrictivas como OFAC y reportes de Buró de DataCrédito. Este
proceso se realiza masivamente debido al volumen de clientes que se maneja en este tipo de organizaciones, es por ello que se
producen retrasos operativos, inconsistencias en los criterios aplicados y riesgos de error humano al vincular clientes que no
cumplen con los criterios establecidos por las compañías o se asignan cupos inadecuados.

Una intervención de automatización resulta pertinente ya que permite estandarizar e integrar un proceso manual a uno algorítmico
que se parametrice de acuerdo con las necesidades específicas de la compañía. Con fines académicos el proyecto se llevará a cabo
mediante estructuras de datos simuladas a través de inteligencia artificial, listas restrictivas y de crédito con el objetivo de realizar
una herramienta en Python que permita de manera automática y transparente determinar si el cliente se aprueba y en qué
condiciones se asignará el crédito a cada uno de ellos (de contado, cupo a 15 días o cupo a 45 días).
